# Node API CI exercise

Use Node 24. Run `npm ci`, `npm run lint`, and `npm test`. Start the API with `npm start`; `/health` returns a healthy JSON response on port 3000.

Workflows demonstrate tests, coverage, read-only cache restore for PRs, dependency auditing, Gitleaks, actionlint, and a CodeQL severity gate. Read Lab 3 in the study module before running failure drills. Never commit real credentials.
